# VOID RUN

A tiny dependency-free browser survival game built as an end-to-end test of ChatGPT's GitHub integration.

## Play locally

Open `index.html` in a browser.

## Controls

- Move: WASD or arrow keys
- Start / restart: Space

## Goal

Survive as long as possible while enemies accelerate and spawn more frequently. Collect cyan energy shards for bonus points and a brief global slow effect.

The high score is stored locally in the browser with `localStorage`.
